# dsh-halt-jobs

Кнопка-пилюля «остановить все фоновые задачи» в шапке сессии, сразу справа от
штатного селектора background jobs.

## Что делает

- Показывает число **живых** фоновых задач сессии (`running` / `stopping`).
  Ноль — пилюля приглушена, больше нуля — красная и кликабельная.
- Клик гасит все `running`-задачи **этой** сессии одним заходом; всплывает
  подпись «Остановлено задач: N».
- Тултип поясняет расхождение с селектором: селектор считает вообще все задачи
  (включая завершённые непрочитанные), пилюля — только те, что можно остановить.

## Как устроено

- **Host** (`src/index.ts`): один аутентифицированный RPC-канал
  `/dsh-halt-jobs` с эндпоинтом `stop-all` через `ctx.connection.rpc.handle`.
  Connection сам применяет Host/Origin-фенсинг и cookie браузерной сессии;
  регистр задач дополнительно сверяет киллера с владельцем. Caller резолвится
  из id сессии через живой реестр агентов — чужие сессии недоступны по
  построению.
- **Client** (`src/client/`): запись `halt-stop-all` (order 100) в слоте
  `conversation.session.header.actions`. Счётчик читает готовую проекцию
  `jobsBySession` через стандартный проп `useSessions` — своего опроса нет;
  единственный вызов по проводу — `stop-all` через `ctx.connection.rpc.call`.

## Сборка

```sh
pnpm install && pnpm build   # lib/index.js + lib/client.js + типы
```

Подключение в профиль:

```sh
dsh plugin --profile web add /Users/alex_quidditch/projects/dsh-plugins/dsh-halt-jobs
```

и перезапуск профиля.
