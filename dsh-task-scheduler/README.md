# dsh-task-scheduler

DSH plugin bundle: persistent AI/скриптовый планировщик задач.

- **Панель** — Настройки → «Планировщик задач»: список задач, CRUD, «▶ Запустить»,
  «⏹ Стоп», тумблер cron, история запусков с логами.
- **AI-задачи** — содержимое `.md` исполняется агентом (fork-сабагент под
  драйвер-агентом с дефолтным пресетом и моделью; sandbox-режим наследуется от
  воркспейс-сессии).
- **Скрипты** — `bun run <файл.ts|js>` с аргументами, ENV и таймаутом.
- **CRON** — 5 полей (`мин час день месяц дн.нед`), тикер 15 с.
- **Триггер из чата** — тул `task_trigger`.
- **Хранение** — `<DSH home>/task-scheduler/tasks.json` (переживает рестарт
  DSH; при первом старте импортирует легаси-стейт из
  `<воркспейс>/.dsh-tasks/tasks.json`, если он есть).

## Установка

```sh
dsh plugin --profile web add link:/path/to/dsh-task-scheduler
# затем перезапустить dsh web
```

## Разработка

```sh
pnpm install
node activation.test.mjs
```
