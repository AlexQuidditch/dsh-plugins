# dsh-vv-context

Порт `/context`-инспектора из vv-opencode: честная панель использования контекстного окна активной сессии.

## Что делает

Кнопка «ⓘ контекст» в утилитной полосе шапки сессии открывает панель с тремя секциями, читаемыми из host-проекций token-meter через framework-хук `useProjection` (живое обновление без опросов):

- **Использование** — дизъюнктные корзины: вход без кэша, кэш-чтение, кэш-запись, вывод;
- **Давление на окно** — последний запрос, оценка следующего, окно модели, занятость в % (прочерк, если окно неизвестно);
- **Состав (оценка)** — system/tools/messages и их доля от запроса.

Оценки не претендуют на точную токенизацию провайдера; проценты могут превышать 100 — полоски лишь клампятся на 100. Отсутствие данных показывается как «—», а не выдуманный ноль.

## Тест

pnpm install --store-dir ../.pnpm-store --offline
pnpm run build
